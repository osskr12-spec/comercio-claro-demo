# Comercio Claro — demo pública

Prototipo estático para explorar la gestión de un pequeño comercio: resumen, inventario, ventas, compras y reportes.

## Datos de ejemplo

Los cambios se guardan en el navegador de cada visitante y no se sincronizan entre usuarios. Esta demo no usa una base de datos compartida ni servicios de IA en producción. No ingreses información real del negocio.

## Archivos

`index.html`, `app.js` y `styles.css`.
